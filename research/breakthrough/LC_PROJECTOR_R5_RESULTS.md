# R5: полный аудит одного каталога, не объявление прорыва

**Результат:** для всех 368 записей публичного каталога построено проверяемое
решение вопроса о преобразовании в CSS-код произвольными локальными Clifford-гейтами.
11 допускают такое преобразование; 357 не допускают. Нерешённых случаев нет.

## Понятно без квантового жаргона

Квантовые коды защищают информацию от ошибок. CSS — важный класс таких кодов.
Иногда код выглядит иначе только из-за выбора базиса отдельных кубитов.
Тогда перед нами не принципиально другой код, а другая запись известного класса.

В исследуемом каталоге уже находили 11 таких случаев, но для остальных проверяли
не все возможные сочетания локальных преобразований. Мы не нашли дополнительных
«CSS-кодов под другой записью». Вместо этого получили для всех остальных короткие
проверяемые свидетельства того, что преобразование невозможно вообще в этом классе
локальных операций. Это более сильная проверка классификации **данного каталога**.

Сертификат здесь — не подпись организации, а список точных двоичных равенств.
У любого подходящего преобразования они должны выполняться. Если их сложение
даёт «0 = 1», такого преобразования не существует. Другая программа может
проверить этот список, не повторяя поиск и не доверяя его внутренним решениям.

Это не новый исправляющий код, не ускорение WaveMind и не измеренное улучшение
квантового компьютера. Новизна метода и массовая/корпоративная полезность
по-прежнему требуют отдельных доказательств.

## Предсказания и результаты

| Предварительное предсказание / проверка | Результат |
|---|---|
| Полностью решить минимум 95% каталога в пределах 600 секунд | 368/368, 100%; 19,7693 секунды всего |
| Найти хотя бы один дополнительный CSS-эквивалентный код | **Опровергнуто на полном каталоге**: дополнительных нет |
| Не противоречить ранее известным положительным случаям | Все 11 подтверждены явными преобразованиями |
| Независимо проверить каждое отрицательное решение | 357/357: противоречие уже в линейных необходимых условиях |
| Число кубитов | 36, 72, 108, 144, 180, 360 |
| Максимальная длина отрицательного сертификата | 119 пар «генератор — вектор аннулятора» |

19,77 секунды включают оба конструктора матриц, поиск, проверку сертификатов
и локальную реализацию 36 равномерных по блокам преобразований. Сам кандидат
суммарно занял 5,40 секунды; ограниченный baseline — 9,14 секунды. Это одиночные
замеры разной по охвату работы, **не доказательство общего ускорения** и не
сравнение с лучшим существующим полным решателем. Исходный пакет авторов
не запускался; его результаты не выдаются за наше воспроизведение пакета.

Предварительные тесты включали 48 малых случайных коммутирующих кодов и известные
положительные/отрицательные примеры со сравнением с полным перебором локальных
Clifford-гейтов. После поправки — 11 тестов R5 (23 вместе с прежними исследованиями).
Проверяющая программа не импортирует алгоритм поиска. Это независимая
реализация, но **не независимый исследователь или экспертная рецензия**.

## Что выяснилось при дополнительной проверке новизны

[Albert, Beyond transversality, Appendix F.2](https://arxiv.org/html/2608.05688v1#A6.SS2)
уже использует сопряжение CSS-проектора произвольным локальным Clifford-кортежем
и связанную двоичную параметризацию. Его лемма предполагает CSS-форму у обоих
пространств и решает другую структурную задачу. Тем не менее это существенное
пересечение: **сам приём сопряжённого проектора нельзя объявлять нашим открытием**.
Эта близкая работа изучена после заморозки R5; результаты опыта не менялись.

В [статье каталога, Appendix F](https://arxiv.org/html/2606.02418v1#A6)
отрицательный результат прямо ограничен проверенными семействами. Здесь
получены сертификаты для полного класса локальных преобразований. Возможная
новая ценность — воспроизводимое закрытие именно этого пробела с маленькими
сертификатами, а не первенство общей алгебраической идеи. Требуется проверить,
не опубликован ли уже такой полный аудит или равносильный алгоритм.

Проверить сохранённые доказательства без повторного поиска:

```sh
python research/breakthrough/verify_r5.py
python -m pytest research/breakthrough/test_lc_projector.py -q
```

Для нового запуска использовать чистый checkout коммита `a15d660...`, Python
3.13.2 и NumPy 2.5.2, затем `experiment_r5.py --output <новый-каталог>`.
Нельзя перезаписывать исходный результат. Время на другой машине может отличаться.
Алгоритм в общем случае экспоненциален по размерности остаточного пространства;
успех на данном каталоге не превращает его в полный полиномиальный решатель.

Следующий научный шаг: проверить отличия от ближайших работ и затем заранее
зафиксировать испытание на независимых семействах кодов, включая случаи, где
линейная часть совместна, но подходящего проектора нет. Для внешней проверки
подготовлены формулировка и сертификаты; никому они автоматически не отправлены.
Оба исходных admission gate всей миссии остаются **false**.
