# Verified Workspace Experience Quickstart

WaveMind can store verified working experience for a specific repository without a cloud account or API key. The workspace flow keeps data under `.wavemind/` inside the project and returns cited Experience Packets instead of raw logs.

## Five-minute local path

From a Git repository:

```bash
python -m pip install wavemind
wavemind workspace --root . init --workspace-id my-agent
wavemind workspace --root . doctor
wavemind workspace --root . demo
wavemind workspace --root . mcp-config --out .wavemind/mcp.json
```

The demo runs a local capture cycle:

1. starts a typed workspace run;
2. captures a tool call and tool result;
3. verifies the outcome with test evidence;
4. approves the generated runbook;
5. recalls a cited Experience Packet from the same persistent store.

## Normal review loop

```bash
wavemind workspace --root . status
wavemind workspace --root . review --action list --json
wavemind workspace --root . review --action approve --experience-id EXP_ID --evidence-id operator-check
wavemind workspace --root . packet "pytest cache permission failure" --domain python --task-type pytest-cache
```

To edit before approval:

```bash
wavemind workspace --root . review \
  --action edit-approve \
  --experience-id EXP_ID \
  --evidence-id operator-edited \
  --title "Pytest cache recovery" \
  --content "Remove .pytest_cache and rerun pytest when cache permissions fail."
```

Deletion is protected:

```bash
wavemind workspace --root . review \
  --action delete \
  --experience-id EXP_ID \
  --confirmation delete:EXP_ID
```

## Generic MCP config

`wavemind workspace mcp-config` writes a provider-neutral server block:

```bash
wavemind workspace --root . mcp-config --out .wavemind/mcp.json
```

Use the generated `wavemind-workspace` server entry in any MCP client that can launch a local command. It points at the workspace memory paths and namespace generated by `workspace init`.

## Data ownership

- Core memory DB: `.wavemind/wavemind.sqlite3`
- Verified Experience DB: `.wavemind/experience.sqlite3`
- Workspace config: `.wavemind/workspace.json`

Disabling or uninstalling a client does not delete these files. Export/import uses a checksummed portable bundle, and imports are rejected when the workspace namespace does not match.
