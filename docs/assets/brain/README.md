# Brain documentation assets

`personal-context.png` is the actual P1-0 context view; `company-context.png` is
the B1-1 context view from the reviewed Task8 implementation at
`04882a13d6d95bd1c07139e1ff332248285fc5e7`. Both were copied unchanged from its
63-test covering run on 2026-09-10. They show synthetic nonsecret fixtures in
real Chrome with actual HTTP and stdio MCP clients. No model was connected;
these are not user-study or business-performance evidence. Context counts,
expiry and estimated size are the captured packet's actual UI values.

`owned-memory-loop.html` / `.svg` and their `-en` counterparts are static offline
explanatory diagrams of context, receipt, external action, outcome, verification
and the next request. They are not application screenshots. Verification does
not automatically admit a procedure. The HTML includes further scope limits.
No remote fonts or scripts are loaded; Georgia, Segoe UI and Consolas are the
observed Windows fallbacks for unavailable Instrument Serif/Geist fonts.

The diagram-design template's MIT copyright and permission notice is embedded
in each file. Preserve it when adapting the sources. The internal full-page
diagram QA PNGs are not distributed as product screenshots or requested exports.
